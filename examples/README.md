# Examples

This directory contains example single-file HTML tools built with Vulcan.

Each file is a stand-alone, disposable tool that can be deployed via:

```bash
curl -s -X POST http://localhost:3000/api/view/deploy \
  -H "Content-Type: application/json" \
  -d @- <<< '{"name": "tool-name", "html": "'"$(cat calculator.html | sed 's/"/\\"/g')"'"}'
```

Or in Claude Code, just say: `"/deploy-view a calculator tool"` and AI generates it.

## Available Examples

| File | Description | Uses Bridge API |
|------|-------------|-----------------|
| `calculator.html` | Minimal dark-themed calculator | `Vulcan.toast()` |

## How These Are Created

All examples in this directory were generated by Claude Code on the fly. They are:

- **Single-file** — one HTML, nothing else
- **Disposable** — deploy, use, discard
- **Local** — all libraries served by Vulcan, no CDN
- **Interactive** — user clicks buttons, sees results, applies changes

The point is that AI can generate these on demand. These files are just archived snapshots.
